## 1. Product research summary (what Fathom actually is)
Fathom records Zoom / Google Meet / Teams calls (bot or bot-free), transcribes them with speaker attribution, and produces AI summaries and action items right after the call. Core surfaces:

**Call page (the heart of the product)**
- Video player + transcript shown chat-style (speaker name, avatar, timestamp per line). Scrolling/clicking the transcript seeks the video; the current line highlights during playback.
- Transcript editing: fix text, reassign a speaker, trim sections.
- **AI Summary** with a **template dropdown** (General/Enhanced, Sales, Sales–BANT, Sales–MEDDPICC, Sales–SPICED, Q&A, Stand-up, 1:1, Project Update, Customer Success, Interview…). Changing template regenerates. Summary is structured markdown (Topics discussed / Key takeaways / Next steps). **Every summary bullet links to the exact timestamp** in the recording. Gear icon lets the user add custom instructions to a template and "Regenerate".
- Summary language dropdown next to template dropdown.
- **Action items**: auto-detected, with assignee, completed checkbox, recording timestamp, user_generated flag; "Copy" button.
- **Follow-up email draft** with a short recap + link to the recording.
- **Highlights**: add from the transcript (hover a line → "+" → choose highlight type/tag e.g. Positive, Pain point, Question, Action item, Decision). Highlights appear as markers on the timeline and in the transcript. Each highlight = a **clip** with its own share link.
- **Share**: Share button → link opens without an account, containing video, transcript, summary. Access options: Anyone with link / Same domain / Only people added.
- **Ask Fathom**: chat about the meeting; answers cite and link to exact transcript moments.
- Meeting type badge (AI-detected, editable dropdown) which picks the default summary template.

**Across meetings**
- Home / "My Calls" list: recent calls grouped by date, title, duration, attendees, meeting type; upcoming meetings from calendar.
- **Search** across all meetings (keyword → exact moment), plus **AI Search / Ask Fathom across all meetings** with citations.
- **Playlists**: curated list of highlight clips from many calls, "Play All", share link. **Folders**: organize full calls.
- Settings: default summary template, auto-record rules, share defaults, integrations (Slack, HubSpot, Salesforce, Asana, Zapier) — stub these.

**Fathom API data shape (use as our model)**: meeting has title, url, share_url, scheduled/recording start & end times, meeting_type, transcript_language, calendar_invitees (name, email, is_external), recorded_by; transcript items {speaker.display_name, matched_calendar_invitee_email, text, timestamp}; default_summary {template_name, markdown_formatted}; action_items {description, user_generated, completed, recording_timestamp, assignee}; highlights {type, summary, timestamp}.

## 3. Tech stack (fixed — do not debate)
- Next.js (App Router, TypeScript, server actions + route handlers), Tailwind, shadcn/ui, lucide-react.
- Supabase: Postgres + Storage (media files). SQL migrations in `supabase/migrations/`.
- Search: Postgres full-text (`tsvector` + GIN) on transcript segments.
- LLM: Anthropic API (`claude-sonnet-5`) via `@anthropic-ai/sdk`, structured JSON outputs validated with zod.
- Transcription: Deepgram (`nova` model, `diarize=true`, `utterances=true`) — fallback AssemblyAI.
- Deploy: Vercel. Env vars documented in `.env.example`.
